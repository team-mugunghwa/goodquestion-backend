# MVP 요건

| **구분** | **요건** | **주요 기능** | **내용** | **세부 설명** | **비고** |
| --- | --- | --- | --- | --- | --- |
| 필수 | 회원가입 및 아이 등록 | 보호자 계정 생성·아이 프로필 관리 | 보호자가 가입하고 서비스를 이용할 아이를 등록 | - 이메일 또는 소셜 로그인 (카카오, 구글, 네이버 중 1개 이상 제공)
- 보호자 계정 아래 여러 아이 프로필 등록 가능
- 아이 이름, 나이 등록 |  |
| 필수 | 메인 화면 | 이어하기·추천 이야기 | 아이가 다음 활동을 바로 시작 | - 진행 중인 이야기 표시와 이어하기 버튼 제공
- 추천 이야기 2~3개 표시
 • 홈, 이야기, 단어장, 마이페이지 표시 | 현재 추천 로직은 미구현 상태이며, 홈 화면 UI 구성을 위해 영역만 우선 배치 |
| 필수 | 이야기 선택 | 이야기 목록·상세 안내 | 아이가 이야기를 선택하고 활동 내용을 확인 | - 이야기 목록에 대표 이미지, 제목, 예상 시간, 주요 주제 표시
- 이야기 선택 시 상세 화면으로 이동
- 상세 화면에 이야기 도입, 상황, 아이 역할 표시
- 주제별 필터링 제공 |  |
| 필수 | 이야기 장면 진행 | 장면·캐릭터 질문 | 이야기 장면을 보여주고 캐릭터가 질문 | - 장면 이미지와 캐릭터 표시
- 상황 설명과 캐릭터 대사 제공
- 캐릭터 음성 자동 재생
- 캐릭터 대사 다시 듣기 제공 |  |
| 필수 | 아이 음성 대화 | 음성 입력·텍스트 변환 | 아이가 캐릭터의 질문에 음성으로 답변 | • 캐릭터 발화 종료 후 마이크 자동 활성화
 • 음성 입력 시작
 • 아이 음성을 텍스트로 변환
 • 아이가 말을 마친 뒤 보내기 버튼을 눌러 발화를 제출
 • 아이의 음성을 텍스트로 변환해 화면에 표시(STT)
 • 아이와 캐릭터의 대화 내역 구분 표시
 • 아이 발화 원문을 세션에 저장 | 캐릭터 발화가 끝나면 효과음과 화면 변화를 통해 아이가 말할 차례임을 안내 |
| 필수 | 발화 분석 및 캐릭터 반응 | 발화 분석·추가 질문·장면 전환 | 아이의 답변을 분석해 캐릭터 반응과 다음 진행을 결정 | • 아이가 보내기 버튼을 누르면 확정된 발화 텍스트를 저장하고 분석 
• 아이가 보내기 버튼을 누르면 발화를 저장·분석
 • 발화에서 생각, 이유, 감정, 관점, 판단, 해결 방법 등의 사고 요소를 
추출한 뒤 현재 장면의 목표 발화 조건과 비교
 • 목표가 부족하면 캐릭터의 성격과 입장을 유지한 추가 질문을 생성
 • 목표를 충족하거나 최대 대화 횟수에 도달하면 다음 장면으로 이동
 • 마지막 장면 완료 후 전체 대화와 분석 결과를 저장
 • 말하기 후 활동으로 전환한다. | 발화 분석과 진행 판단 기준은 별도 알고리즘 자료로 제공 |
| 필수 | 말하기 후 활동 | 이야기 재구성·생각 정리 | 주요 장면의 순서를 맞춘 뒤 핵심 단어를 활용해 이야기를 다시 말함 | • 주요 장면 카드 4~5개를 무작위로 제시
 • 아이가 카드를 이야기 순서대로 배열
 • 배열 순서가 정답일 시, 핵심 단어 3~4개 제공
 • 카드와 단어를 참고해 전체 이야기를 음성으로 재구성
 • 텍스트로 전환 및 표시
 • 발화 내용과 활동 완료 여부 저장 |  |
| 추가 | 보호자 리포트 | 활동 결과·발화 변화 | 보호자가 아이의 말하기 결과를 확인 |  |  |
| 추가 | 단어 저장 | 모르는 단어 저장·확인 | 대화 중 만난 단어를 다시 볼 수 있도록 저장 | - 모르는 단어 질문 시 저장
- 쉬운 뜻과 이야기 속 문장 제공
- 음성 듣기 제공
- 좋아하는 단어 저장 | 별도 단어장 화면은 후순위 가능 |
| 추가 | 캐릭터 마음 변화 | 표정·태도 변화 | 아이의 발화에 따라 캐릭터 반응 변화 | - 아이의 발화 내용에 따라 캐릭터 표정 또는 태도 변화 | 몰입도 향상 목적 |
